# Хроника освобождения Дона

Интерактивная карта, визуализирующая ход Великой Отечественной войны в Ростовской области (1941–1943).

## О проекте

Этот проект представляет собой интерактивную визуализацию ключевых исторических событий Великой Отечественной войны на территории Ростовской области. Он охватывает период от начала войны до полного освобождения региона в августе 1943 года.

### Основные функции
- **Интерактивный таймлайн**: автоматическое воспроизведение хроники событий.
- **Динамическая карта**: отображение линий фронта и направлений ударов войск.
- **Исторические справки**: детальное описание битв, оккупации и подвигов солдат.
- **Умная навигация**: автоматическая остановка плеера на значимых датах.

## Технологии

- **React 19**
- **Leaflet** (картография)
- **Tailwind CSS** (стилизация)
- **Motion** (анимации)
- **Lucide React** (иконки)

## Локальная разработка

### Инсталляция
Для запуска проекта вам понадобится [Node.js](https://nodejs.org/).

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
